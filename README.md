# Minecraft b1.7.3 Babric

Instance with b1.7.3 babric included for [PrismLauncher](https://github.com/PrismLauncher/PrismLauncher) (should work on MultiMC aswell)

## Prerequisites

-   Java 17
-   Prism Launcher / MultiMC

## Usage

1. Download the repository as .zip
2. Unzip the `b1.7.3-babric` folder inside the zip in your instances directory
3. Enjoy

## Compatibility

Most fabric mods are not compatible with Babric and will crash your game.
